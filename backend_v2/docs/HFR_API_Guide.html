1. Overview

The Health Facility Registry (HFR) External API provides programmatic access to Nigeria's comprehensive registry of health facilities, pharmacies, laboratories, and imaging centres. It is maintained by the Federal Ministry of Health.

The API is designed around REST principles. All responses are returned in JSON. It uses API key authentication and supports pagination, filtering, sorting, and full-text search.

Who is this for? — Government agencies, health-tech developers, researchers, NGOs, and anyone building applications that rely on accurate health facility data in Nigeria.

Key Features

FacilitiesSearch, filter, and retrieve details on hospitals, clinics, and health centres
PharmaciesAccess pharmaceutical premises data with licensing status
LaboratoriesQuery laboratory data including accreditation status
ImagingRetrieve radiology / diagnostic imaging centres
LookupsStates, LGAs, wards, facility types, ownership, statuses, and more

2. Getting Started

Step 1 — Request an API Key

Send a POST request to the public key-request endpoint, or fill out the form on the developer portal.

POST /api/v1/request-key
Content-Type: application/json

{
  "name": "Jane Doe",
  "email": "jane@example.com",
  "organisation": "My Health App",
  "use_case": "Building a facility locator to help Nigerians find nearby hospitals."
}

Step 2 — Wait for Approval

Your request will be reviewed by an administrator. Once approved, your API key will be sent to the email address you provided. You can check the status at any time:

GET /api/v1/request-key/status?email=jane@example.com

Step 3 — Start Making Requests

Include your API key in the X-API-Key header of every request.

curl -H "X-API-Key: hfr_your_api_key_here" \
     https://hfrapi.fmohconnect.gov.ng/api/v1/facilities

3. Authentication

Every request to a protected endpoint must include your API key in the X-API-Key HTTP header.

HeaderValue
X-API-KeyYour API key (starts with hfr_)
Acceptapplication/json (recommended)
Keep your key secret. Do not embed API keys in client-side code or public repositories. If you believe your key has been compromised, contact the HFR team immediately to have it revoked and regenerated.

Authentication Errors

StatusCodeDescription
401api_key_requiredMissing X-API-Key header
401invalid_api_keyKey not recognised
403api_key_inactiveKey has been deactivated
403api_key_expiredKey has passed its expiry date

4. Rate Limiting

Each API key has an individual rate limit (default: 60 requests per minute). Exceeding this limit returns a 429 Too Many Requests response.

Rate Limit Headers

HeaderDescription
X-RateLimit-LimitMaximum requests allowed per minute
X-RateLimit-RemainingRequests remaining in the current window
Retry-AfterSeconds until the window resets (only on 429)
Tip: If you need a higher rate limit for production workloads, mention this in your API key request or contact support.

5. Response Format

All responses use a consistent JSON envelope:

{
  "status": "success",
  "data": { ... },
  "meta": {
    "current_page": 1,
    "per_page": 25,
    "total": 43210,
    "last_page": 1729
  },
  "links": {
    "first": "...?page=1",
    "last": "...?page=1729",
    "prev": null,
    "next": "...?page=2"
  }
}
FieldTypeDescription
statusstringsuccess or error
dataobject / arrayRequested resource(s)
metaobjectPagination metadata (list endpoints only)
linksobjectPagination navigation URLs (list endpoints only)
messagestringHuman-readable message (error responses)

6. Pagination

List endpoints are paginated. Control pagination with these query parameters:

ParameterDefaultRangeDescription
page11 – ∞Page number

7. Error Handling

Error responses follow the same envelope with "status": "error":

{
  "status": "error",
  "message": "The given data was invalid.",
  "errors": {
    "email": ["The email field is required."]
  }
}

HTTP Status Codes

14. Code Examples

cURL

# List facilities in Lagos state (state_id = 25)
curl -s -H "X-API-Key: hfr_your_api_key" \
  "https://hfrapi.fmohconnect.gov.ng/api/v1/facilities?state_id=25&per_page=10"

# Get a single facility
curl -s -H "X-API-Key: hfr_your_api_key" \
  "https://hfrapi.fmohconnect.gov.ng/api/v1/facilities/12345"

# Get facility statistics
curl -s -H "X-API-Key: hfr_your_api_key" \
  "https://hfrapi.fmohconnect.gov.ng/api/v1/facilities/statistics"

Python (requests)

import requests

API_KEY = "hfr_your_api_key"
BASE    = "https://hfrapi.fmohconnect.gov.ng/api/v1"

headers = {"X-API-Key": API_KEY}

# Search for hospitals in Abuja
resp = requests.get(f"{BASE}/facilities", headers=headers, params={
    "search": "Abuja",
    "per_page": 10
})
data = resp.json()

for facility in data["data"]:
    print(facility["facility_name"], "-", facility["state"])

JavaScript (fetch)

const API_KEY = "hfr_your_api_key";
const BASE    = "https://hfrapi.fmohconnect.gov.ng/api/v1";

async function getFacilities(stateId) {
  const url = `${BASE}/facilities?state_id=${stateId}&per_page=20`;
  const res = await fetch(url, {
    headers: { "X-API-Key": API_KEY }
  });

  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}

// Usage
getFacilities(25).then(json => {
  console.log(`Found ${json.meta.total} facilities`);
  json.data.forEach(f => console.log(f.facility_name));
});

PHP (Guzzle)

use GuzzleHttp\Client;

$client = new Client([
    'base_uri' => 'https://hfrapi.fmohconnect.gov.ng/api/v1/',
    'headers'  => ['X-API-Key' => 'hfr_your_api_key'],
]);

// List pharmacies in a state
$response = $client->get('pharmacies', [
    'query' => ['state_id' => 25, 'per_page' => 50]
]);

$data = json_decode($response->getBody(), true);
echo "Total: " . $data['meta']['total'];

15. Versioning

The API is versioned via the URL path: /api/v1/. The current (and only) version is v1.

Every response includes an X-API-Version header indicating the version that handled the request.

Backwards compatibility: When a new version is released, the previous version will continue to be available for at least 12 months with a deprecation notice. We will notify all registered API key holders before sunsetting any version.
